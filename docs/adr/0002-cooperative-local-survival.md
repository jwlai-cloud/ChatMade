# Cooperative survival with local operation

Status: Accepted, 2026-10-24. The user accepted all three recommendations from the first grilling round.

Viewers cooperate to rescue the streamer after creating the threat; the streamer dodges for 60 seconds with three hearts and no attack controls or boss health. This prioritises shared authorship and teamwork while avoiding competing-side balancing and combat scope; outcomes are SURVIVED or CAUGHT.

The first release runs locally alongside OBS. Hosted operation is deferred to avoid account-security, deployment and operating-cost scope before the core loop is validated. This accepts installation friction for streamers and judges.

These decisions resolve the audience-role, survival and initial delivery questions only. ADR 0001's remaining architecture and generation proposals are not yet approved, and the grilling review remains open.
