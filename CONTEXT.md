# ChatMade

Viewers create a monster together, then cooperate to help the streamer survive it.

## Language

**Encounter**:
A timed survival challenge in which the streamer dodges the audience-created monster's attacks.
_Avoid_: Boss fight, combat round

**Rescue**:
Cooperative viewer help that gives the streamer relief from the monster during an encounter.
_Avoid_: Viewer attack, competing team

**Survived**:
The streamer remained alive until the encounter timer expired.
_Avoid_: Defeated, monster killed

**Caught**:
The streamer lost all hearts before the encounter timer expired.
_Avoid_: Monster victory points

**Recipe**:
A proposed combination of creature appearance, supported attack and weakness, shown for host approval before reveal.
_Avoid_: Generated game code

**House suggestion**:
A clearly labelled built-in suggestion used when a category has no eligible viewer suggestion. It has no viewer author credit.
_Avoid_: Viewer submission, simulated viewer credit

**Host approval**:
The streamer's confirmation that a selected recipe is suitable to reveal and play. Audience votes recommend a recipe but do not bypass this decision.
_Avoid_: Automatic approval
